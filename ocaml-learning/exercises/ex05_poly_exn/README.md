## 这题练什么

2026-08-10 讲了两块东西，**都还没写过代码**：

- **B1 类型变量 `'a`** —— 洞、同名同类型、不同名无约束、**`'a` 不可触碰**
- **B3 异常** —— `failwith` / `try … with` / 多分支 / 兜底放最后

这题就是把这两块过一遍手。**⛔ 不用 `option`，也不用自己定义带参数的类型**——
那两样已经推迟了，这里一点都不涉及。

## 七道题

| # | 函数 | 练什么 |
|---|---|---|
| 1 | `swap` | **`'a` 和 `'b` 是两个洞** —— 第二条测试专门验「它们也可以相同」 |
| 2 | `repeat` | **`'a` 不可触碰**：只能原样放进表里。外加递归造表 |
| 3 | `head_or` | **同名 `'a` 必须同类型**：默认值和元素是同一个洞 |
| 4 | `safe_div` | `try … with` 最小形状，一条分支 |
| 5 | `to_int_or` | 接住 `Failure`（`int_of_string` 抛的那个） |
| 6 | `nth_or` | **同一个调用可能抛两种异常**，两条分支；而且带着 `'a` |
| 7 | `classify` | **多分支 + 兜底放最后**；外加「try 各分支类型必须一致」 |

**1–3 是 `'a`，4–7 是异常，第 6 题把两者叠在一起。**

## 提示

- `match` / `try` 的骨架都已经替你写好，**你只填 `->` 右边**（TODO 1、2 是整个函数体）
- 没做完也能编译运行，跑起来会逐条报「还没做」
- 第 4、5、6、7 题的 `try` 后面那一段也要你填（不只是 `->` 右边）

## ⚠️ 一个会让你困惑的现象（这是骨架的副作用，不是 bug）

还没开始做的时候跑一遍，你会看到「`classify 正常` → 还没做（TODO 7c）」——
**明明是正常路径，为什么报的是 `Failure` 那条分支的编号？**

因为骨架里 `try` 后面放的占位符是 `failwith "TODO 7a"`，
**它抛出的 `Failure` 正好被这个函数自己的 `| Failure msg ->` 分支接住了**。

**这恰好演示了这一题要练的东西**：`try … with` 真的在工作，
`failwith` 抛的就是 `Failure`。开始做题之后这个现象自然消失。
