## 答案

```ocaml
let describe (name : string) (n : int) : string =
  Printf.sprintf "%s = %d" name n

let avg_trunc (a : int) (b : int) : int =
  int_of_float (float_of_int (a + b) /. 2.)

let bump_twice (r : int ref) : int =
  r := !r + 1;
  r := !r + 1;
  !r

let swap (a : int ref) (b : int ref) : unit =
  let tmp = !a in
  a := !b;
  b := tmp
```

（四个都实测跑过，八条自测全 OK。）

## 常见错法（**这才是有教学价值的部分**）

### TODO 1

| 错法 | 后果 |
|---|---|
| 用 `Printf.printf` | **类型错误**：`printf` 返回 `unit`，函数要求返回 `string`。**这正是复习轮第 6 题的洞** |
| `"%s = %s" name n` | **编译错误**：`%s` 要 string，`n` 是 int。格式串是编译期检查的 |
| 用 `^` 手工拼：`name ^ " = " ^ n` | **编译错误**：`^` 两边都要 string，`n` 是 int。得先 `string_of_int n` |

`name ^ " = " ^ string_of_int n` 其实是**对的**，只是没用上 `sprintf`。可以接受，但要指出 `sprintf` 才是这题想练的。

### TODO 2

| 错法 | 后果 |
|---|---|
| `(a + b) / 2` | **编译通过，但结果错**。整数除法直接丢小数：`(-3 + -4) / 2 = -3`（碰巧对）但 `(3+4)/2 = 3` 也碰巧对……⚠️ **这题的两条用例都测不出这个错**，见下方「注」 |
| `(a + b) /. 2.` | **编译错误**：`/.` 要 float，`a + b` 是 int。报错会精确指向 `(a + b)` |
| `float_of_int (a + b) / 2.` | **编译错误**：`/` 是整数除法，两边要 int |
| `int_of_float (...)` 忘了写 | **类型错误**：算出来是 float，函数要求 int |
| 以为 `int_of_float (-3.5)` 是 `-4` | **结果错**。它朝零截断 → `-3`。这是知识点 5 里明确警告过的坑 |

> **注**：`(a + b) / 2` 在这两条用例上恰好都能得到正确答案（3 和 -3），
> 所以自测**发现不了**这个错法。如果用户是这么写的，**要主动指出来**——
> 整数除法在 `avg_trunc 3 4` 上碰巧对，但那是巧合，不是因为写对了。
> 可以现场加一条 `avg_trunc 1 2`（正确答案 1，整数除法也是 1……同样测不出）。
> **真正能区分的是先转 float 的思路本身**，讲清楚即可，不必强行造用例。

### TODO 3

| 错法 | 后果 |
|---|---|
| `r + 1` | **类型错误**：`r` 是 `int ref` 不是 int，要 `!r` |
| `r := r + 1` | **类型错误**：右边 `r + 1` 里 `r` 还是 ref |
| 用 `,` 或换行代替 `;` | 逗号会造元组；纯换行则是语法错误 |
| 最后写成 `r` 而不是 `!r` | **类型错误**：返回 `int ref`，要求 `int` |
| 只写一次 `r := !r + 1` | 结果差 1，`[XX]` 会报出来 |

### TODO 4

| 错法 | 后果 |
|---|---|
| `a := !b; b := !a` | **编译通过，结果错**：`!a` 已经被改成 `b` 的值了，两个盒子最后都是 `b` 的原值。<br>⚠️ **这是经典的交换 bug**，C 里一模一样。自测 `swap 1 2` 会报 `[XX] 期望 2,1，实际 2,2` |
| `let tmp = a in` | 存的是**盒子本身**不是内容，后面 `b := tmp` 类型错误（`int ref` vs `int`） |
| 想 `return ()` | OCaml 没有 `return`。函数体最后一个表达式就是返回值，`b := tmp` 本身就是 `unit` |

## 这道题堵的三个洞（对应 2026-08-06 快问快答）

| 复习轮的洞 | 这题哪里堵 |
|---|---|
| 分号左边必须是 `unit`，且不知道原因 | TODO 3、4 必须连用 `;`，写错会撞 `Warning 10` |
| `sprintf` 和 `printf` 混了 | TODO 1 用 `printf` 直接类型错误 |
| 类型注解 ≠ 强制转换 | TODO 2 只能靠 `float_of_int` / `int_of_float`，写 `(x : float)` 不管用 |
