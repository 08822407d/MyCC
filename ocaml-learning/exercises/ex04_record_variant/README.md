## 几个容易踩的点

- **浮点乘法是 `*.` 不是 `*`**（TODO 2）
- **底价是 `int`，系数是 `float`，两个不能直接相乘**（TODO 4，知识点 5）
- **圆周率就用 `3.14`**，测试是按这个算的，别用 `Float.pi`
- **定义记录用冒号 `itm : item`，造值用等号 `itm = Shirt`**
