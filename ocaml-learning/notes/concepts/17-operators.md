## 17.1 算术：两套，不通用

| int | float | 说明 |
|---|---|---|
| `+ - * /` | `+. -. *. /.` | **带点 = 浮点版** |
| `mod` | —— | `7 mod 2 = 1`，**不带点却只吃 int** |
| —— | `**` | `2. ** 10. = 1024.`，**不带点却只吃 float，右结合** |
| `~-` | `~-.` | **一元负号**，`~- 5 = -5` |

`7 / 2 = 3`（截断），`7. /. 2. = 3.5`。

## 17.2 比较：全是多态的

```
( = ) : 'a -> 'a -> bool
```

| 运算符 | 含义 | ⚠️ |
|---|---|---|
| `=` | **结构相等** | `"a" = "a"` → **true** |
| `==` | **物理相等** | `"a" == "a"` → **false** ← C/C# 背景头号陷阱 |
| `<>` | 结构不等 | |
| `!=` | 物理不等 | `"a" != "a"` → **true** |
| `< > <= >=` | 多态比较 | `[1;2] < [1;3]` → true（字典序） |
| `compare` | 返回 `-1/0/1` | `compare 3 5` → `-1` |

**日常一律 `=` / `<>`。** `==` 只在判断「是不是同一个对象」时用（他在 `ref` 别名那次用过）。

## 17.3 逻辑

`&&`、`||`（都短路）、**`not` 是函数不是符号**。
⚠️ `&` 和 `or` 是废弃的老写法。

## 17.4 拼接三兄弟

| 运算符 | 干什么 | 代价 |
|---|---|---|
| `^` | **字符串**拼接 | |
| `@` | **列表 + 列表** | **O(n)** |
| `::` | **元素 + 列表** | **O(1)** |

三个都右结合。

## 17.5 ⭐ 位运算：全是单词，不是符号

**这是从 C 过来最容易撞的一块。**

| OCaml | C | 例子 |
|---|---|---|
| `land` | `&` | `6 land 3` → `2` |
| `lor` | `\|` | `6 lor 3` → `7` |
| `lxor` | `^` | `6 lxor 3` → `5` |
| `lnot` | `~` | `lnot 6` → `-7` |
| `lsl` | `<<` | `1 lsl 4` → `16` |
| `lsr` | `>>`（逻辑） | `48 lsr 2` → `12` |
| `asr` | `>>`（算术） | `(-48) asr 2` → `-12` |

**C 的四个符号在 OCaml 里全是别的东西**（实测）：

```
6 & 3    →  Error: Unbound value (&)
6 | 3    →  Error: Syntax error        ← | 是 match 分支分隔符
6 ^ 3    →  类型错误                    ← ^ 是字符串拼接
1 << 4   →  Error: Unbound value (<<)
```

⚠️ **`lsr` vs `asr` 在负数上差别巨大**（OCaml 的 int 是 **63 位**）：

```
(-48) asr 2  →  -12
(-48) lsr 2  →  2305843009213693940
```

## 17.6 应用与管道

| | 类型 | 作用 |
|---|---|---|
| `\|>` | `'a -> ('a -> 'b) -> 'b` | 数据在前，改**阅读顺序** |
| `@@` | `('a -> 'b) -> 'a -> 'b` | **就是函数应用**，只省括号 |

`List.length [1;2;3]` ≡ `List.length @@ [1;2;3]` ≡ `[1;2;3] |> List.length`，全是 `3`。

## 17.7 ⛔ C 里有、OCaml **没有**的（**就是坑到他那次的**）

| C | OCaml | 替代 |
|---|---|---|
| `? :` | **没有** | `if c then a else b`——OCaml 的 `if` 本身有值 |
| `++` `--` | **没有** | `ref` 用 `incr r` / `decr r` |
| `+=` 等复合赋值 | **没有** | `r := !r + 1` |
| 逗号运算符 | **没有** | 逗号是**造元组**的 |
| `&` `\|` `^` `<<` `>>` | **不是位运算** | 见 17.5 |

## 17.8 ⛔ 看着像运算符，其实不是

| 符号 | 真身 |
|---|---|
| `->` | **语法**，三处互不相干：类型 / `fun` / `match` 分支 |
| `\|` | `match` 分支、变体定义的分隔符 |
| `;` | 列表分隔符 / 顺序执行（两个身份） |
| `:` | 类型标注 ← **就是它把用户的 `? :` 报成 `Unbound type constructor`** |
| `_` | 通配符**模式** |

## 17.9 优先级（只记会咬人的）

从高到低：

```
函数应用 f x                  ← 最高
**  lsl  lsr  asr             ← 右结合
*  /  mod  land  lor  lxor
+  -
::                            ← 右结合
@  ^                          ← 右结合
=  <>  <  >  ==  !=
&&
||
|>                            ← 左结合
@@                            ← 右结合
if / match / fun / let        ← 最低
```

### ⚠️⚠️ 和 C 最要命的一处不同（实测两边）

```
C:      1 << 2 + 1  =  8      移位比加法【低】→ 1 << (2+1)
OCaml:  1 lsl 2 + 1 =  5      移位比加法【高】→ (1 lsl 2) + 1
```

**C 的移位优先级低是公认的设计失误，OCaml 修正了。**
但这意味着**从 C 搬过来的移位表达式会静默算出不同的值**——不报错，结果不对。
→ **移位一律加括号。**

## 17.10 前缀 vs 中缀：看首字符

| 首字符 | 位置 |
|---|---|
| `!` `?` `~` | **前缀**（一元） |
| 其他符号 | **中缀**（二元） |

实测自定义的都成立：`let ( !? ) x = x + 1 in !? 5` → `6`；`~%`、`?~` 同理。

**标准库的前缀运算符只有三个**：`!`（解引用）、`~-`、`~-.`。

### ⭐ 用户主动问的：`!` 和 `*` 有没有一元版本

**`!` 有，`*` 没有**（`*r` → `Syntax error`）。这正好补上 C 的对应关系：

| C | OCaml |
|---|---|
| `*p`（一元，读） | **`!r`** |
| `*p = v`（一元，写） | `r := v` |
| `a * b`（二元，乘） | `a * b` |

> **C 用 `*` 同时干「乘法」和「解引用」，OCaml 拆开了**——所以 OCaml 里不存在
> 「这个 `*` 是乘还是解引用」的歧义。

⚠️ 再提一次：**`!` 不是逻辑非**，逻辑非是 `not`。

### ⚠️ 纯语法的坑：`( * )` 必须留空格

```
( * )  →  int -> int -> int = <fun>     ✅
(*)    →  Error: Comment not terminated  ❌ (* 开了注释
```

**因为 `(*` 是注释开始符**，和「注释可嵌套」是同一个根源。
其他运算符没这问题，但**统一加空格是社区习惯**。
