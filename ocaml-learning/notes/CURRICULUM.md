## 五、和两本教材的差异（**故意的，别改回去**）

两本教材的顺序都查证过（2026-08-08）：

- **Cornell CS 3110《OCaml Programming》** — `https://cs3110.github.io/textbook/`
  章序：Basics → **Data and Types**（Lists→Variants→Records&Tuples→Advanced Pattern Matching→Type Synonyms→**Options**→Association Lists→ADT→**Exceptions**→Trees）
  → **Higher-Order Programming**（HOF→**Map→Filter→Fold**→Beyond Lists→**Pipelining**→Currying）
  → Modular Programming → Mutability → Concurrency → Correctness → Data Structures → **Interpreters**
- **ocaml.org 官方教程** — `https://ocaml.org/docs`
  语言主线只有四篇：Values and Functions → **Data Types and Pattern Matching** → **Lists**（含**高阶函数 + `List` 模块 + 尾递归**）→ **Loops and Recursions**（含 for/while、遍历列表、数组、`and`）；中级另有 **Error Handling**

| 我的安排 | 教材 | 理由 |
|---|---|---|
| `'a` 多态**提前** | 两本都零散穿插 | 它是后面所有类型签名的钥匙 |
| `fold` **单独一步** | 两本都和 map/filter 并列 | 按用户难度评估，这是唯一会卡的点 |
| for/while/数组 **降级为顺带提** | 官方单列一节 | 他 C 里全会，且社区不用 |
| 模块**放最后** | 官方在中级层 | 抽象度对他最高，要等有落点 |
| **每步都配练习** | 教材章末统一出题 | 2026-08-06 复习轮的教训 |

## 六、两个已知的断层（教材对照出来的，别忘）

1. **`map` / `filter` / `fold` 整块空白** —— CS 3110 单列一章，**官方更狠，直接放进「Lists」那一篇**：
   在官方眼里学完列表就该会这三个，它们是列表的一部分，不是进阶话题。
2. **⚠️ 我欠过一个纠正（2026-08-08 已当面说明）**：我一直说「递归代替循环」，
   可能让他以为 **OCaml 没有循环**。实际有 `for` / `while`（实测通过），
   只是不能 `break`（`Unbound value break`）、循环体必须是 `unit`、想攒结果得配 `ref`。
   **社区不用循环不是因为没有，是因为循环在不可变的世界里不好用。**
