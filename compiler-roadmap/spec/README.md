## 什么时候开始往这里写

当 `../notes/feature-inventory.md` 的特性取舍**基本收敛**、
相关决策进入 ✅ 已定状态之后，把结论**成文**搬到这里。

判据很简单：**`notes/` 是「我们怎么想到的」，`spec/` 是「结论是什么」。**
一个新人只读 `spec/` 应该能知道这门语言长什么样，**不需要读讨论过程**。
